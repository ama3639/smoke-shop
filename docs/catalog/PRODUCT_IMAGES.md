# تصاویر محصولات وینستون

مرحله فعلی: دریافت ۱۴ تصویر آماده‌شده توسط فروشنده از مدل‌های مختلف وینستون برای تکمیل فهرست محصولات هوم‌پیج. تصاویر هنوز در مخزن قرار نگرفته‌اند؛ نام دقیق مدل‌ها پس از دریافت و مشاهده فایل‌ها تطبیق داده می‌شود.

## مسیر فایل‌ها

داخل پروژه: `frontend/public/images/products/winston/`

در ویندوز: `D:\Smokeshop\frontend\public\images\products\winston`

تصاویر را با نام‌های `01` تا `14` و پسوند اصلی فایل قرار دهید؛ مثلاً `01.png`، `02.webp` یا `03.jpg`. فرمت‌های PNG، WebP و JPG/JPEG پذیرفته‌اند. نام شماره‌دار فقط برای تطبیق تصویر و مدل در این مرحله است و محصول جدیدی ایجاد نمی‌کند.

فایل اصلی، نسبت ابعاد، نوشته‌ها و هشدار روی بسته را حفظ کنید. تصاویر تمام پاکت/باکس را نشان دهند؛ پس‌زمینه شفاف در صورت وجود حفظ شود. فعلاً فایل‌ها را برش، کشیدگی یا بازطراحی نکنید.

## تطبیق با محصول

اگر نام مدل در تصویر خوانا نیست، نام مربوط به آن شماره و نوع تصویر (پاکت یا باکس) را در گفتگو اعلام کنید. فایل‌ها پس از مشاهده با مدل‌های کاتالوگ تطبیق داده می‌شوند. قیمت، موجودی و مشخصات عرضه از تصویر حدس زده نمی‌شوند.

پس از دریافت تصاویر و تطبیق مدل‌ها، اتصال به داده کاتالوگ و نمایش آن‌ها در هوم‌پیج انجام می‌شود. قرار دادن فایل در این پوشه به‌تنهایی فهرست محصولات فعلی Django را تغییر نمی‌دهد.

## ارسال با Git

ابتدا آخرین تغییرات پروژه را بگیرید:

```powershell
Set-Location D:\Smokeshop
git pull --ff-only origin main
```

سپس تصاویر را در مسیر بالا کپی کنید و فقط پوشه تصاویر را ثبت و ارسال کنید:

```powershell
git add frontend/public/images/products/winston
git commit -m "assets: add Winston product photos"
git push origin HEAD:main
```

فایل‌ها در `backend/media` یا پوشه‌ای خارج از پروژه قرار نگیرند؛ `backend/media` عمداً از Git خارج است.
