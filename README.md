# اسموک‌شاپ — زیرساخت ساده فروشگاه و کاتالوگ

نسخه **0.6.1** · Alpha کاتالوگ سیگار · 2026-10-11

کاتالوگ فارسی سیگار برای فروشنده و پخش تکی/عمده، با تمرکز اولیه بر **وینستون** و امکان افزودن برندهای دیگر از مدیریت. رابط راست‌به‌چپ با فونت محلی **وزیرمتن** و تصویر کامل بسته‌ها در هوم‌پیج، با حرکت ملایم هنگام اسکرول. کاتالوگ به Django متصل است؛ نام مدل‌ها از تصاویر ارسالی تطبیق داده شده؛ موجودی و اطلاعات عرضه نیازمند تأیید فروشنده است.

## امکانات اجراشده

- کاتالوگ سیگار، دسته‌بندی، برند، جست‌وجوی فارسی با یکسان‌سازی ی/ک و فیلتر موجودی و عرضه تکی/عمده.
- دود ویدیویی در سراسر صفحه اصلی با اسکرول، تصویر هوم‌پیج با اسکرول و بازشدن مشخصات با یک لمس؛ توقف و کاهش حرکت دستگاه.
- ۱۴ مدل وینستون با تصاویر ارسالی فروشنده، نمایش کامل قاب تصویر و نسخه‌های WebP سبک؛ PNGهای اصلی حفظ شده‌اند.
- خانواده‌های کلاسیک، XS، نوا، سوپراسلیم، ایکس استایل و کامپکت؛ تعداد نخ/باکس تا تأیید فروشنده ثبت نشده است.
- مشخصات تعداد نخ در بسته و بسته در کارتن؛ اطلاعات نمونه نیازمند جایگزینی با داده واقعی‌اند.
- صفحه کالا، تصویر قابل بارگذاری و منبع/تاریخ/سطح اطمینان سازگاری.
- پنل Django برای کالا، موجودی، دسته، شعبه، مدل و قواعد سازگاری.
- وضعیت حقوقی در سطح SKU؛ کنترل خرید در سرور و flagهای پیش‌فرض خاموش.
- سبد مهمان، حفاظت CSRF، تأیید کمکی ۱۸+ و جداسازی سبدها.
- درخواست سفارش بدون پرداخت، رزرو تراکنشی، جلوگیری از تکرار، پیگیری با نشست و لغو رزرو.
- نقش‌های مدیر کاتالوگ و ناظر حقوقی، Audit Log و دفتر تغییرات موجودی.
- تست API و مرورگر، بررسی TypeScript، build و GitHub Actions.

## شروع سریع در ویندوز

Python ≥ 3.12 و Node.js ≥ 22 نصب کنید، سپس:

```powershell
Set-Location D:\Smokeshop
py -3.12 scripts/setup.py
py -3.12 scripts/dev.py
```

فروشگاه: `http://localhost:3000` · ادمین: `http://localhost:8000/admin/`

ساخت مدیر:

```powershell
.\backend\.venv\Scripts\python.exe backend\manage.py createsuperuser
```

در Linux/macOS از `python3` و `backend/.venv/bin/python` استفاده کنید. Docker و سرویس‌های AI برای اجرای محلی لازم نیستند.

راهنمای کامل نصب، فعال‌سازی، backup، تست و تولید: [LOCAL_SETUP](docs/deployment/LOCAL_SETUP.md).

## معماری این نسخه

Next.js + TypeScript برای رابط، Django + DRF serializers برای API و مدیریت، SQLite برای اجرای محلی و PostgreSQL برای تولید و تست هم‌زمانی. lockfile و requirements نسخه‌ها را تثبیت می‌کنند. فونت وزیرمتن با مجوز SIL Open Font License محلی بارگذاری می‌شود.

ماژول‌ها در یک برنامه Django قرار دارند تا نگهداری ساده باشد. Redis، Celery، Meilisearch، pgvector و LangGraph تا زمان نیاز واقعی اضافه نشده‌اند. مستندات معماری جامع مسیر آینده را توصیف می‌کنند؛ کد و این راهنما وضعیت اجرایی فعلی را مشخص می‌کنند.

## محدوده نسخه اولیه

فروش اینترنتی سیگار طبق قواعد پروژه غیرفعال است؛ حتی تنظیم اشتباه وضعیت حقوقی، آن را در API قابل خرید نمی‌کند. نمونه‌های وینستون `IN_PERSON_ONLY` هستند. وضعیت هر کالای جدید `REVIEW_REQUIRED` است. زیرساخت سبد و درخواست سفارش فقط برای اقلام غیردخانی دارای تأیید حقوقی، دسته و flag فعال باقی مانده است. درگاه پرداخت متصل نیست؛ درخواست سفارش به معنی پرداخت یا سفارش قطعی نیست. تأیید سن فعلی جایگزین احراز قانونی سن نیست.

موشن اسکرول و دود با CSS و APIهای مرورگر ساخته شده تا وابستگی و راه‌اندازی اضافه نداشته باشد. AI سلامت و امکانات رشد مراحل بعد هستند. موارد باقی‌مانده تولید در راهنمای نصب ثبت شده‌اند.
