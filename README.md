# اسموک‌شاپ — زیرساخت ساده فروشگاه و کاتالوگ

نسخه **0.2.0** · Alpha زیرساخت · 2026-10-09

رابط فارسی راست‌به‌چپ با فونت محلی **وزیرمتن**، پالت عاجی/زغالی/مسی و طراحی واکنش‌گرا. کاتالوگ به Django متصل است؛ داده نمونه صرفاً نمایشی است.

## امکانات اجراشده

- کاتالوگ، دسته‌بندی، جست‌وجوی فارسی با یکسان‌سازی ی/ک، فیلتر موجودی و مدل سازگار.
- صفحه کالا، تصویر قابل بارگذاری و منبع/تاریخ/سطح اطمینان سازگاری.
- پنل Django برای کالا، موجودی، دسته، شعبه، مدل و قواعد سازگاری.
- وضعیت حقوقی در سطح SKU؛ کنترل خرید در سرور و flagهای پیش‌فرض خاموش.
- سبد مهمان، حفاظت CSRF، تأیید کمکی ۱۸+ و جداسازی سبدها.
- درخواست سفارش بدون پرداخت، رزرو تراکنشی، جلوگیری از تکرار، پیگیری با نشست و لغو رزرو.
- نقش‌های مدیر کاتالوگ و ناظر حقوقی، Audit Log و دفتر تغییرات موجودی.
- تست API و مرورگر، بررسی TypeScript، build و GitHub Actions.

## شروع سریع در ویندوز

Python ≥ 3.12 و Node.js ≥ 22 نصب کنید، سپس:

```powershell
Set-Location D:\Smokeshop
py -3.12 scripts/setup.py
py -3.12 scripts/dev.py
```

فروشگاه: `http://localhost:3000` · ادمین: `http://localhost:8000/admin/`

ساخت مدیر:

```powershell
.\backend\.venv\Scripts\python.exe backend\manage.py createsuperuser
```

در Linux/macOS از `python3` و `backend/.venv/bin/python` استفاده کنید. Docker و سرویس‌های AI برای اجرای محلی لازم نیستند.

راهنمای کامل نصب، فعال‌سازی، backup، تست و تولید: [LOCAL_SETUP](docs/deployment/LOCAL_SETUP.md).

## معماری این نسخه

Next.js + TypeScript برای رابط، Django + DRF serializers برای API و مدیریت، SQLite برای اجرای محلی و PostgreSQL برای تولید و تست هم‌زمانی. lockfile و requirements نسخه‌ها را تثبیت می‌کنند. فونت وزیرمتن با مجوز SIL Open Font License محلی بارگذاری می‌شود.

ماژول‌ها در یک برنامه Django قرار دارند تا نگهداری ساده باشد. Redis، Celery، Meilisearch، pgvector و LangGraph تا زمان نیاز واقعی اضافه نشده‌اند. مستندات معماری جامع مسیر آینده را توصیف می‌کنند؛ کد و این راهنما وضعیت اجرایی فعلی را مشخص می‌کنند.

## محدوده نسخه اولیه

فروش نمونه‌ها و ثبت سفارش پیش‌فرض خاموش است؛ وضعیت هر کالای جدید `REVIEW_REQUIRED` است. کالا بعد از تأیید حقوقی کتبی، فعال‌شدن دسته و flag قابل خرید می‌شود. درگاه پرداخت متصل نیست؛ درخواست سفارش به معنی پرداخت یا سفارش قطعی نیست. تأیید سن فعلی جایگزین احراز قانونی سن نیست.

AI سلامت، موشن سه‌بعدی اسکرول و امکانات رشد در مراحل بعد و طبق درخواست‌های بعدی پیاده می‌شوند. موارد باقی‌مانده تولید در راهنمای نصب ثبت شده‌اند.
