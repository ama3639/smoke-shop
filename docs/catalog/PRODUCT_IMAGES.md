## مسیر و نحوه نمایش

- PNGهای اصلی: `frontend/public/images/products/winston/01.png` تا `14.png`.
- نسخه‌های نمایشی: `frontend/public/images/products/winston/optimized/01.webp` تا `14.webp`.
- هر دو نسخه ابعاد 1122×1402 دارند. فایل اصلی، نوشته‌ها، هشدار و قاب کامل حفظ شده‌اند. تبدیل WebP فقط برای کاهش حجم است.
- فهرست هوم‌پیج و صفحه محصول قاب کامل عکس را با `object-fit: contain` نشان می‌دهند؛ عکس روی وجوه یک بسته مصنوعی کشیده نمی‌شود.
- خروج نخ روی عکس با CSS انجام می‌شود؛ ماوس/کیبورد پیش‌نمایش را فعال می‌کنند و روی لمس، بار اول پیش‌نمایش و بار دوم مشخصات را باز می‌کند.
- صحنه بالای هوم‌پیج و بخش عمده هنوز از طراحی قبلی استفاده می‌کنند؛ بازطراحی آن‌ها مرحله جداگانه است.

## اتصال به کاتالوگ

نگاشت در `backend/shop/winston_catalog.py` ثبت شده است. `seed_demo` هفت مدل جدید را اضافه می‌کند، شناسه هفت مدل قبلی را حفظ می‌کند و مسیر تصویر خالی را تکمیل می‌کند. تصویر آپلودشده ادمین و مسیر سفارشی اولویت دارند. داده نمونهٔ قدیمی بدون ویرایش ادمین ثبت‌شده به خانواده صحیح منتقل می‌شود؛ قیمت، موجودی، وضعیت حقوقی، فعال‌بودن و flagها حفظ می‌شوند.

تعداد نخ/بسته و بسته/باکسِ تأییدنشده `null` است. اعداد نمایشی قدیمی ۲۰/۱۰ فقط برای رکوردهای دست‌نخورده حذف می‌شوند. اطلاعات واقعی ویرایش‌شده حفظ می‌شود. حالت‌های تکی/عمده فعلی معرفی کاتالوگ هستند؛ عرضه و موجودی هنوز نیازمند تأیید فروشنده‌اند. فروش اینترنتی سیگار فعال نمی‌شود.

## به‌روزرسانی در ویندوز

```powershell
Set-Location D:\Smokeshop
git pull --ff-only origin main
py -3.12 scripts/setup.py
py -3.12 scripts/dev.py
```

اگر PNGها تغییر کردند، فایل‌های WebP را بازتولید و همراه اصل فایل در Git ثبت کنید:

```powershell
.\backend\.venv\Scripts\python.exe scripts\prepare_product_images.py
git add frontend/public/images/products/winston
git commit -m "assets: update Winston product photos"
git push origin HEAD:main
```

برای اصلاح نگاشت یا افزودن مدل بعدی، `winston_catalog.py` را تغییر دهید و `seed_demo` را اجرا کنید. مسیرهای موجود خودکار بازنویسی نمی‌شوند؛ اصلاح مسیر یک محصول موجود از ادمین انجام می‌شود. `backend/media` برای آپلود ادمین است و وارد Git نمی‌شود.
