# فهرست تصمیم‌های مورد تأیید مالک — Smoke Shop

این سند فقط مواردی را نگه می‌دارد که مقدار یا سیاست تجاری/عملیاتی‌شان از سورس قابل استنباط نیست. Codex نباید این خانه‌ها را با حدس پر کند. کارهای مستقل از این تصمیم‌ها در سند «اصلاحات بدون تأیید جداگانه» قابل انجام‌اند.

## تصمیم‌های قبلاً قطعی‌شده

این موارد دوباره از مالک پرسیده نشوند:

- پروژه سفارشی است؛ WordPress و WooCommerce نمی‌خواهیم.
- خوداظهاری ۱۸+ برای این مرحله کافی است؛ احراز رسمی سن اضافه نشود.
- زبان فارسی، RTL و هویت بصری Titanium Silver حفظ شود.
- پنل مدیریتی و تجربهٔ ثبت/بارگذاری قیمت فروشنده باید ساده‌تر و جامع‌تر شود.
- عکس واقعی کالا لازم است؛ تصویر مصنوعی نباید به‌جای عکس همان SKU نمایش داده شود.

## قاعدهٔ اجرای Codex

تا وقتی مالک موردی را تأیید نکرده، مقدار مالی/قانونی/عملیاتی جدید برای آن وارد نشود. Codex باید تصمیم‌های دریافت‌شده را در خلاصهٔ اجرا ثبت کند و فقط بخش‌هایی را پیاده کند که پاسخ لازم را دارند. تأیید یک ردیف به‌معنای مجوز deploy، انتشار یا تغییر شاخه نیست.
